Bienvenido a este curso de CSS, si quieres aprender todo sobre el diseño web, seguro que este curso gratuito de CSS te vendrá perfecto para comprender la base del diseño de las páginas web ¡El CSS!

Pero ¿Qué aprenderemos en este curso de CSS?

Para empezar, lo primero que aprenderemos será a entender bien qué es realmente CSS (os adelanto que no es ni un lenguaje de programación ni de estructuras), una vez entendamos qué es (correctamente), podremos entender muchas más cosas, como su alcance.

Pero esto es solamente la parte teórica, en la parte práctica nos meteremos de lleno en CSS, veremos cómo lo podemos ejecutar (de diferentes formas),

Además veremos tanto los selectores (que nos permiten seleccionar algo de la web), como los propios atributos, que nos permitirán cambiar el tamaño, color, fondo, altura, etc.

En definitiva, este curso intenta ser un curso transversal pensando para que podamos tener una fuerte base de CSS para empezar ya mismo con el desarrollo web.

Por otra parte, tendremos una clase únicamente dedicada a la documentación ¡Es importante saber buscar! ¡Al igual que saber encontrar!

Esperamos que te guste este curso.

## 2. Selectores en CSS

Bienvenido a esta segunda clase del curso de CSS.

Como ya sabemos por la clase anterior, CSS es un lenguaje de estilos o diseño, lo que quiere decir que simplemente le tenemos que decir qué queremos modificar y cómo lo queremos modificar.

Pues bien, en esta segunda clase aprenderemos a realizar esa primera parte, es decir “seleccionar qué queremos modificar”, parece poco, pero los selectores ¡Son la mitad de CSS!

Para ello tendremos que aprender que existen diferentes clases de selectores, veremos que existen los básicos que son los de etiqueta, los de clase y los de ID que nos van a servir para el 99% de nuestro código.

No obstante veremos los avanzados, para todos los alumnos que quieran un código más limpio y realizar algunas acciones un poco más avanzadas (como seleccionar todas las etiquetas que cumplan unos requerimientos).

## 4. Flex

Bienvenido a esta cuarta clase del curso de CSS. En esta clase aprenderemos una de las cosas que personalmente me parecen más alucinantes de CSS3 ¡Flex!

Cuando digo que Flex es una de las cosas más alucinantes de Flex no lo digo por decir, como aprenderemos en la clase, la historia de Flex se remonta un par de décadas atrás, cuando no existían los teléfonos móviles (y mucho menos inteligentes) ni las tablets.

En aquella época (años 90 y algo del 2000), para crear la estructura de las páginas webs se utilizaban tablas con filas y columnas, al fin y al cabo, todas las pantallas tenían más o menos las mismas medidas, por lo que se podía controlar bastante bien.

No obstante, con la aparición de los smartphones, todas las webs hasta el momento no funcionaron ya que las pantallas de los móviles eran pequeñas, por lo que en esos años (2000) se tuvo que crear dos webs, una para móviles y otra para ordenadores.

Con el tiempo se vio que eso no podía ser y se utilizó una tecnología llamada “float” que permitía hacer las webs responsives. ¿Problema? ¡Es horrible utilizarla! ¡No estaba pensando para eso! ¡A la mínima se descuadraba todo!

Por ello, con el tiempo (no hace mucho) apareció Flex ¡La solución para desarrollar webs responsive! Es nativo y es fácil de utilizar, así que ¡Veamos la clase!
