¿Wordpress o Web desde cero? Muchos programadores nos hemos llegado hacer esa pregunta cuando hemos tenido que realizar una web ya sea para nosotros o para clientes nuestros.

Como muchos programadores, también menosprecie a WordPress, pensando que no era más que una herramienta inicialmente creada para hacer blogs y que sólo le servía a *noobs* (programadores no expertos) para vender páginas webs sin tocar código. Pocos programadores expertos no han pensado esto alguna vez en su vida.

No obstante, con el tiempo entendí que WordPress es más que una plataforma para hacer webs sin tocar casi código, de hecho ahora mismo uso WordPress para crear páginas web complejas y de una manera rápida y sencilla y así tener tiempo para programar los diferentes software que vendo.

Así pues, vamos a ver las ventajas que tiene WordPress para una empresa:

## Ventajas de usar WordPress

### Ahorras tiempo

Ahorras tiempo, de he hecho, ahorras **mucho** tiempo. Subir los ficheros al servidor y configurar la base de datos te pueden costar 5 minutos. Elegir un diseño de themeforest o uno de los gratuitos te puede costar como mucho 3 horas. La maquetación la haces desde un panel de control por lo que es muy rápido, incluso si necesitas modificar los ficheros CSS lo podrás hacer desde el propio panel.

De hecho, en menos de una jornada laboral (8 horas) podrás tener lista la web para el cliente, con un panel de control sencillo para que el mismo gestione la página web.

### Ahorras (mucho) dinero

Si tiene un negocio deberás de saber lo que es el coste de oportunidad, pongamos que hacer una web sencilla en WordPress te ha costado 5 horas y que la misma web desde cero, sin panel de control ni nada, te habría costado 30 horas, eso querrá decir que habrás perdido 25 horas que podrías haber estado usando en conseguir clientes o en realizar otras tareas que te habrían dado más dinero.

Visto de otra forma más sencilla, si tu hora de trabajo la valoras en 20€ querrá decir que esas 25 horas que has perdido haciendo la web desde cero te han costado 500€.

Además, si tienes una empresa y más tarde necesitas contratar a alguien para que cambie alguna cosa, un experto en wordpress siempre va a salir más barato y lo va hacer más rápido que un experto programador.

### Incluye un blog y tiene panel de control

WordPress se creó como un blog por lo que incluye de serie la posibilidad de que vayan publicando artículos (Inbound Marketing), cosa que ayudará enormemente a la hora de hacer popular el blog en Google y en las redes sociales.

Además, WordPress incluye un panel de control, algo que de haberse hecho desde cero habría aumentado x10 el tiempo necesario para hacer la página web y nunca habría tenido tantas opciones como WordPress.

### Miles de Plugins

Y lo más importante, WordPress tiene decenas de miles de [plugins públicos](https://es.wordpress.org/plugins/) y gratuitos que puedes instalar con un simple click. Podrás desde hacer hacer una pasarela de pago con Paypal para vender unos productos en cinco minutos, hasta crear una red social con un foro para tus usuarios registrados.

Tiene miles de plugins que son los que realmente hacen increíble WordPress.

Además, si tantas ganas tienes de programar, podrás crear (y vender) tus propios plugins para tu página web y así hacerla mucho más personalizada.

Pues sí, WordPress es potentísimo y lo recomiendo siempre para hacer páginas web ya que gracias a su plugins puedes ir haciendo tu web (incluso multi-idiona) más grande poco a poco.

Para entender el potencial que llega a tener WordPress, en una ocasión me ofrecieron un trabajo en una red social que se encontraba en tres países y que había empezado como un blog wordpress con cuatro plugins, hasta al final ser una red social con millones de usuarios activos (todavía en WordPress). Lógicamente, alcanzado estas metas ya poco quedaba del motor de WordPress que empezaron usando.
